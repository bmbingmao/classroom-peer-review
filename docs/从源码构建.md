# 备选路径：在 NAS 上从源码构建（需要 NAS 能上外网）

一般不需要用这个——直接用 `peer-review-image.tar.gz` 导入镜像就行（不需要 NAS 联网到 Docker Hub）。

什么时候用它：
- NAS 不是 x86_64（比如 ARM），现成镜像跑不了
- 你改过源码，想重新打镜像

## 用法

```bash
mkdir -p ~/peer-review && cd ~/peer-review
tar xzf /path/to/app-source.tar.gz
cp .env.example .env 2>/dev/null || true   # 没有就手写，参考 deploy/.env.example
sudo docker compose -f docker-compose.yml up -d --build
```

## 如果拉不动基础镜像

国内网络下 `node:24-alpine` 可能拉不下来。在 NAS 上配镜像源：

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json >/dev/null <<'EOF'
{ "registry-mirrors": ["https://docker.m.daocloud.io", "https://docker.1ms.run", "https://dockerproxy.net"] }
EOF
sudo systemctl restart docker
```

`npm install` 也要能连上 registry.npmjs.org（一般没问题）。
